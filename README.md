# Minesweeper

A neon minesweeper in your browser. Three sizes, a safe first click, chording, flags, a timer. Plain HTML, CSS and JavaScript in one file, no build step, no dependencies.

## Play

**[Play in your browser](https://cubicobelus.github.io/minesweeper/)**

## Controls

- Click: dig.
- Right-click, or long-press on touch: flag.
- Click an opened number whose flags match it: clear the rest around it.
- `R` or the face button: new game.

## Run locally

Open `index.html` in any browser.
